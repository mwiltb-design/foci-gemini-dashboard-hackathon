# Pi-Dashboard Shortcuts & Slash Commands

## ⌨️ Common Slash Commands

| Command | Action |
| :--- | :--- |
| `/login` | Open AI provider authentication dialog |
| `/model` | Switch active language model |
| `/clear` | Clear current chat context while keeping session history |
| `/compact` | Summarize and compact conversation history |
| `/help` | Display quick reference guide |

## 🕹️ Keyboard Navigation

* `Ctrl + Enter` : Send message / execute command
* `Ctrl + K` : Focus chat input
* `Ctrl + Shift + F` : Global file search
* `Ctrl + ~` : Toggle embedded terminal (if enabled)
* `Esc` : Close active modal or cancel running generation
