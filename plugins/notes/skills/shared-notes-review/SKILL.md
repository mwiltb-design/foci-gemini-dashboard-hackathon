# Review Shared Notes

1. Use `plugin_notes_list_notes` to read the current notes.
2. Summarize only the information needed for the user's request.
3. Do not add, edit, or delete notes.
4. If the read tool is unavailable, explain that the Shared Notes plugin and PI read access must both be enabled in Plugins.
